> Обновлено: 2026-07-23

## Что делает бот

Это маркетинговый Telegram-бот Юлии Гоголевой о психологии и отношениях. Он помогает человеку не потеряться в материалах: выдаёт два бесплатных PDF-гида, проводит пять психологических тестов и показывает рубрикатор постов канала.

Через бота можно купить видеоуроки и практикумы с оплатой через Tribute, записаться в клуб или на практикум, перейти к психологу, на сайт, в канал или во внешний бот «Микрошаг». Лиды, результаты тестов и значимые действия сохраняются в Notion. Отдельно бот собирает аналитику по своим сценариям, сайту и продажам и показывает её на закрытом HTML-дашборде.

Администратор получает уведомления о регистрациях и продажах, может посмотреть предзаписи и запустить рассылку.

## Из чего состоит

В проекте 12 Python-файлов:

| Файл | За что отвечает |
| --- | --- |
| `main.py` | Точка входа FastAPI-приложения. Регистрирует Telegram webhook при старте, запускает автосохранение статистики и содержит HTTP-маршруты для Telegram, Tribute, событий сайта, health check и дашборда. |
| `handlers.py` | Обрабатывает сообщения и кнопки Telegram: меню, состояния пользователя, диплинки, отправку PDF, изображений и видео, регистрации, уведомления администратору и рассылки. |
| `config.py` | Читает обязательные и опциональные переменные окружения, хранит ссылки продуктов и пути к локальным файлам. |
| `texts.py` | Хранит основные тексты для пользователя: приветствие, гайды, клуб, психолог, продукты, fallback и сообщение после оплаты. |
| `articles.py` | Хранит 10 рубрик с тремя основными постами в каждой. Остальные публикации загружаются из `rubrics_all_posts.md`. |
| `quiz.py` | Тест типа привязанности: 8 вопросов и 4 результата. |
| `deprivation_quiz.py` | Тест «Эмоциональный голод»: 10 вопросов, уровни Д1–Д4 и предложение практикума. |
| `conversation_quiz.py` | Короткий тест поведения в конфликте: 5 вопросов и 5 вариантов результата. |
| `conversation_quiz_v2.py` | Расширенный тест конфликта: 9 балльных вопросов, вопрос об истощении и 11 одиночных или комбинированных результатов. |
| `escape_quiz.py` | Тест «Точка побега»: 12 вопросов и 13 результатов с разными паттернами поведения. |
| `notion_leads.py` | Создаёт и обновляет лиды в Notion, получает данные для дашборда, предзаписей и аудиторий рассылок. |
| `stats.py` | Считает события бота, сайта, кампаний и продаж. Хранит данные в памяти, в Upstash Redis или резервном JSON-файле. |

## Как запускается и деплоится

Проект работает на Python 3.12 — версия указана в `.python-version`. В `requirements.txt` перечислены четыре зависимости без закреплённых версий: `fastapi`, `uvicorn`, `httpx` и `python-multipart`.

Команда запуска берётся из `Procfile`:

```text
uvicorn main:app --host 0.0.0.0 --port $PORT
```

Целевая платформа проекта — Railway: на это указывают переменные `PORT` и `RAILWAY_PUBLIC_DOMAIN`, путь `/data` и комментарии в коде. При старте приложение загружает статистику, при необходимости добавляет исторические продажи, регистрирует Telegram webhook по публичному домену Railway и запускает автосохранение раз в 300 секунд.

При этом в репозитории нет `Dockerfile`, `railway.json` и CI-конфигурации. Поэтому связь GitHub с Railway и реальные настройки сервиса по этому коду подтвердить нельзя.

## Внешние сервисы

- **Telegram Bot API** — принимает обновления через webhook и отправляет сообщения, документы, изображения, видео и кнопки.
- **Notion API** — работает как CRM для лидов, результатов тестов и предзаписей.
- **Tribute** — даёт ссылки на оплату и присылает уведомления об успешных покупках.
- **Upstash Redis** — опционально хранит аналитику и кеш Telegram `file_id`. Без него постоянное хранение статистики зависит от резервного JSON-файла и подключённого Railway Volume.
- **Railway** — запускает web-процесс и даёт публичный HTTPS-домен.

## Переменные окружения

Здесь только имена и назначение переменных. Значения токенов и других секретов в документации хранить не нужно.

### Обязательные

Без этих переменных приложение не импортируется:

| Переменная | Назначение |
| --- | --- |
| `MARKETING_BOT_TOKEN` | Токен Telegram-бота. |
| `ADMIN_CHAT_ID` | Telegram ID администратора. |
| `NOTION_TOKEN` | Токен интеграции Notion. |
| `NOTION_LEADS_DB_ID` | ID базы лидов Notion. |

### Платформенные

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт web-процесса, который использует команда из `Procfile`. Обычно его задаёт платформа. |
| `RAILWAY_PUBLIC_DOMAIN` | Публичный домен Railway для регистрации Telegram webhook. Без него приложение запустится, но webhook автоматически не установит. |

### Опциональные

| Переменная | Назначение |
| --- | --- |
| `TRIPWIRE_URL` | Ссылка на урок «Нам надо поговорить». |
| `ESCAPE_LESSON_URL` | Ссылка на практикум «Точка побега». |
| `HUNGER_LESSON_URL` | Ссылка на материал «Эмоциональный голод». |
| `DASHBOARD_TOKEN` | Токен доступа к аналитическому дашборду. |
| `TRIBUTE_API_KEY` | Ключ для проверки подписи webhook от Tribute. |
| `UPSTASH_REDIS_URL` | Адрес Upstash Redis для постоянной статистики и кеша файлов. |
| `UPSTASH_REDIS_TOKEN` | Токен доступа к Upstash Redis. |
| `STATS_FILE` | Путь к резервному JSON-файлу со статистикой. |
