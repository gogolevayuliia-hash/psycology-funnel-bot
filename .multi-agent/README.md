# .multi-agent/ — служебная папка мультиагентного режима

Наличие этой папки означает: проект подготовлен под конвейер, Claude ведёт сложные задачи
по скиллу `/multi-solo` (проблема → ресёрч → план → тест-план → код → тесты → критик → ворота).
Схема `multi-build` (Codex-кодер + Opus-ревьюер) убрана 13.08.2026 — сессии ниже от неё остались
как история.

## Структура

```
.multi-agent/
  README.md                  ← этот файл
  sessions/<дата>-<slug>/    ← одна папка = одна задача (сессия)
    PROBLEM.md               ← постановка задачи
    RESEARCH.md              ← отчёт ресёрча
    PLAN.md                  ← план реализации
    REVIEW.md                ← вердикт критика
```

По набору файлов в папке сессии всегда видно, докуда дошёл конвейер — на этом построено
возобновление: скажи Claude «продолжи», и он подхватит с нужного этапа.

Файлы здесь можно читать и показывать — это и есть «журнал» задачи. Руками менять не надо.
