# .multi-agent/ — служебная папка мультиагентного режима

Наличие этой папки означает: проект мультиагентный, Claude ведёт задачи по конвейеру
`multi-build` (проблема → ресёрч → план → код → ревью → merge с подтверждением).

## Структура

```
.multi-agent/
  README.md                  ← этот файл
  sessions/<дата>-<slug>/    ← одна папка = одна задача (сессия)
    PROBLEM.md               ← постановка задачи + разрешённые агенты
    RESEARCH.md              ← отчёт ресёрча (Codex researcher или Claude)
    PLAN.md                  ← план реализации (всегда пишет Claude)
    REVIEW.md                ← вердикт ревью (Opus)
  last-<role>.md             ← финальное сообщение последнего запуска Codex (тех. файл)
```

По набору файлов в папке сессии всегда видно, докуда дошёл конвейер — на этом построено
возобновление: скажи Claude «продолжи», и он подхватит с нужного этапа.

Файлы здесь можно читать и показывать — это и есть «журнал» задачи. Руками менять не надо.
