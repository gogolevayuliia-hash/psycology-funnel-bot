# PLAN — стартовый wiki для бота воронки

## Цель и критерии готовности

Два новых файла в `wiki/`, правдивых и в стиле Юли:
- `wiki/index.md` — оглавление;
- `wiki/overview.md` — обзор бота.

## Сложность: normal

## Шаги

1. `wiki/index.md` — точка входа:
   - заголовок и одна строка, что это за проект;
   - строка `> Обновлено: 2026-07-23`;
   - список доков со ссылками (пока один: [overview.md](overview.md) — «Что за бот, из чего
     состоит, как запускается»);
   - короткое правило «начинай чтение отсюда».

2. `wiki/overview.md` — обзор, СТРОГО по фактам из RESEARCH.md:
   - строка `> Обновлено: 2026-07-23` и ссылка назад на [index.md](index.md);
   - **Что делает бот** — маркетинговый Telegram-бот воронки: гайды-PDF, 5 тестов,
     рубрикатор постов, продажи через Tribute, лиды в Notion, аналитический дашборд;
   - **Из чего состоит** — таблица «файл → назначение» по 12 .py-файлам (main.py,
     handlers.py, config.py, texts.py, articles.py, 5 quiz-файлов, notion_leads.py,
     stats.py). Формулировки — из RESEARCH.md, без выдумок;
   - **Как запускается и деплоится** — Python 3.12 (`.python-version`), зависимости из
     requirements.txt (fastapi/uvicorn/httpx/python-multipart), команда из Procfile
     (`uvicorn main:app ...`), платформа Railway, вебхук Telegram ставится при старте;
   - **Внешние сервисы** — Telegram, Notion (CRM лидов), Tribute (оплаты), Upstash Redis
     (опц. аналитика), Railway;
   - **Переменные окружения** — тремя группами: обязательные (MARKETING_BOT_TOKEN,
     ADMIN_CHAT_ID, NOTION_TOKEN, NOTION_LEADS_DB_ID), платформенные (PORT,
     RAILWAY_PUBLIC_DOMAIN), опциональные (остальные из RESEARCH.md). Значения секретов
     НЕ приводить — только имена и назначение.

- Каждый упомянутый .py-файл реально существует в корне проекта.
