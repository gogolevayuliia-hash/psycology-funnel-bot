# PROBLEM — стартовый wiki для бота воронки

## Постановка

У проекта funnel_bot нет документации (ни wiki/, ни README). Создать короткий стартовый
wiki по привычному стилю Юли: точка входа `wiki/index.md` + обзорный документ.

## Критерии готовности

- Есть `wiki/index.md` — оглавление со ссылками.
- Есть `wiki/overview.md` — что за бот, из каких частей состоит (12 .py-файлов),
  как запускается/деплоится, ключевые интеграции (Telegram, Notion).
- Тексты правдивые: основаны на реальном коде, а не на догадках. Файлы, которых нет, не
  упоминаются; факты (деплой, переменные) — из кода (config.py, Procfile, requirements.txt).
- Стиль как в других проектах Юли: у каждого дока строка `> Обновлено: <дата>`, ссылки
  между доками, простой человеческий язык.

## Ограничения

- Только новые файлы в `wiki/`. Код бота НЕ трогать. Существующий контент
  (rubrics_all_posts.md, картинки, pdf) не трогать.
- Ничего не деплоить.
