# Проверка секрета на настоящем HTTP-сервере

> **Переснято 21.08.2026 после круга 2.** Прошлый прогон относился к коду со строковым
> сравнением секрета; после замены на сравнение байтов старый отчёт был недействителен.

Запущен uvicorn с текущим кодом на 127.0.0.1:8757 (порт проверен на занятость — самая
первая попытка на 8099 попала в чужой сервер и дала ложные 200, результат отброшен).

```
сервер мой (PID 57353)
без заголовка:        HTTP 403  (ждём 403)
неверный секрет:      HTTP 403  (ждём 403)
кириллица в секрете:  HTTP 403  (ждём 403, НЕ 500)
верный секрет:        HTTP 200  (ждём 200)
--- лог: припаркованная копия ---
WARNING:main:PUBLIC_URL not set — webhook not configured
WARNING:main:PUBLIC_URL not set — автосохранение статистики выключено, чтобы не затирать снимок боевой копии
```

Третья строка — баг, найденный кругом 2: `hmac.compare_digest` на строках требует ASCII
с обеих сторон, а заголовок приходит снаружи. Публичный `/webhook` отдавал 500 вместо 403.

Две последние строки — предпосылка К9: ровно так поведёт себя копия на Railway после merge,
где `PUBLIC_URL` не задан. Вебхук она не тронет и статистику не перезапишет.
