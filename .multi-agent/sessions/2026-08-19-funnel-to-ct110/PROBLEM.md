# PROBLEM — доперенести psycology-funnel-bot с Railway на CT 110

Дата: 2026-08-19 · slug: `funnel-to-ct110` · ветка `multi/2026-08-19-funnel-to-ct110`

## Постановка

Бот воронки блога PSYcology (`@gogolevajuls_bot`) 06.08.2026 числился переехавшим с Railway
на свой контейнер CT 110 `funnel`. По факту переезд не доведён: **вебхук Telegram всё ещё
смотрит на Railway**, а копия на CT 110 работает вхолостую. Юля просит доперенести — сделать
CT 110 единственным рабочим местом бота.

## Критерии готовности

1. Вебхук Telegram указывает на `https://funnel.gogolevajuls.org/webhook`.
2. Апдейты реально доходят до контейнера на CT 110 — подтверждено логами `funnel-app`.
3. `getWebhookInfo`: `pending_update_count` не растёт, `last_error_message` пуст.
4. Smoke-прогон бота через `bot-test` зелёный, транскрипт в `EVIDENCE/`.
5. Состояние (счётчики, лиды) не потеряно: подтверждено, что обе копии смотрят в один Upstash
   Redis, либо данные перенесены явно.
6. Том Railway забэкаплен в `Desktop/claude/wiki/backups/`.
7. Доки обновлены, предупреждение «бот живёт на Railway» снято, бэклог-пункт 8 закрыт.

## Ограничения и решения Юли

- **Уровень проверки бота: smoke** (`/start` + основные кнопки + транскрипт). Форма задана
  19.08.2026. Инструмент — MCP `bot-test`, тест-юзер `@stickers_support`, **не основной аккаунт**.
- **Копию на Railway держим неделю**, не удаляем в этой сессии: сервис остаётся живым, но без
  вебхука — это откат в одну команду. Снос — отдельной сессией после 26.08.2026.
- Прод с живой аудиторией: переключение делать быстро, окно простоя минимальное, откат наготове.
- Секреты (`MARKETING_BOT_TOKEN`, токены Upstash/Notion/Tribute) **не печатать** в чат, логи
  и артефакты. Брать из окружения на сервере.
- Пока вебхук не переключён — на Railway ничего не трогать.

## Откат

Вернуть вебхук на `https://psycology-funnel-bot-production.up.railway.app/webhook` одной
командой `setWebhook`. Сервис на Railway живой и задеплоен, состояние в общем Redis —
возврат мгновенный, потери только за секунды переключения.

## Чего НЕ делаем

- Не удаляем сервис и том на Railway в этой сессии (решение Юли).
- Не трогаем код воронки: задача инфраструктурная, правки логики бота вне объёма.
- Не разбираем DNS и Cloudflare — тоннель уже настроен и работает.
