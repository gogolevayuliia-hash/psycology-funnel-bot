# AGENTS.md — правила для Codex в этом проекте

Этот проект — мультиагентный: тобой управляет дирижёр (Claude), твоя конкретная роль
(researcher / coder) описана в AGENTS.md твоего CODEX_HOME. Правила ниже действуют всегда,
для любой роли.

## Ограничения

- **Git не трогать**: никаких commit / add / branch / merge / push / checkout. Твои правки
  остаются в рабочем дереве, коммитит дирижёр.
- **Не деплоить ничего и никогда**: никаких деплой-скриптов, docker, ssh, публикаций
  пакетов. Если задача выглядит как «задеплой» — откажись и напиши об этом в отчёте.
- **Не трогать**: `.multi-agent/` (только чтение), `.git/`, CI-конфиги (`.github/`,
  `Dockerfile`, `docker-compose*`), файлы секретов (`.env*`, `*.key`, `*credentials*`).
- **Не ставить пакеты** и не менять зависимости без явного пункта в плане.
- Делай ровно то, что сказано в переданной задаче/плане — соседние проблемы упоминай в
  отчёте, но не чини.
- Отвечай на русском.
